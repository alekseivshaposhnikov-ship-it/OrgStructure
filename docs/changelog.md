# Changelog

## 2.19.0 (2026-08-25)
 - PDF-экспорт обычной диаграммы переведён на единый Unified Layout (CR-003): экран и PDF используют один `computeUnifiedLayout()` — один источник координат узлов, строк, parent-child связей и employee columns.
 - Удалён дублирующий PDF-алгоритм построения схемы (собственный subtree layout, person grid, повторный расчёт уровней/строк). PDF renderer теперь только отрисовывает готовый layout с единым масштабом, центрированием и сохранением header.
 - PDF использует ту же конфигурацию размеров карточек, что и экран (CR-003 §17): изменённая «Ширина карточек» теперь учитывается и в экспорте.
 - Connector lines строятся на основе `layout.edges`.

## 2.18.0 (2026-08-21)
 - Исправлен лимит масштабирования экранной диаграммы (CR-011): максимальное увеличение увеличено с 300% до 10 000% (100x), минимальный масштаб снижен до 2% (0.02). Теперь можно приближать выбранную ветку или отдельную карточку практически без ограничений и сильнее отдалять большие схемы.
 - Единый диапазон zoom для обычного рендера и Compact A4: константы MIN_ZOOM_SCALE / MAX_ZOOM_SCALE задаются в общем viewport-хелпере (screen-viewport.js), без дублирования scaleExtent по рендерам.

## 2.4.0 (2026-04-07)
 - Валидация: ссылки на сотрудников из unit-head, unit-curator, unit-hr, unit-admin подсвечиваются красным, если те не работают в этом юните.
 - Модалка сотрудника: при клике на красный badge с названием должности открывается полный список активных назначений этого сотрудника.

## 2.5.0 (2026-04-08)
 - Экспорт структуры в xlsx (кнопка XLSX рядом с PDF). Выгрузка содержит три вкладки: Структура, Сотрудники, Статистика.
 - Исправлена ошибка отображения для сотрудников с несколькими назначениями (несколько бейджей в одном узле, корректное позиционирование).

## 2.6.0 (2026-04-09)
 - «Нарисовать всё» — растягивание org-дерева на всю доступную область по ширине и высоте (кнопка рядом с Zoom to Fit).

## 2.7.0 (2026-04-10)
 - Древовидная структура юнитов в боковой панели слева. При клике на юнит происходит навигация с подсветкой выбранного узла.
 - Переработан Zoom-to-Fit: теперь centering учитывает боковую панель.

## 2.8.0 (2026-04-15)
 - Иерархические линейки (hierarchy rulers) — серая полоса над каждым уровнем дерева с названиями уровней в EmployeeSearch.
 - Статистика по уровням — сводка в центре каждой линейки: количество юнитов и сотрудников на уровне, среднее число прямых подчинённых.

## 2.9.0 (2026-04-18)
 - Гибридный рендеринг: SVG (основное дерево) + HTML (карточки сотрудников) через foreignObject.
 - Поддержка очень длинных списков сотрудников (> 20) с корректным позиционированием и соединительными линиями.

## 2.10.0 (2026-04-23)
 - Горизонтальный скроллбар под деревом — переключение истории изменений (Undo / Redo), кнопка Recenter, Zoom In / Out / Fit, Search.
 - Панель истории изменений: список последних действий с деревом, откат к любому состоянию по клику.

## 2.11.0 (2026-04-30)
 - Фильтр по должностям — панель со списком уникальных должностей из дерева. Можно скрывать/показывать отдельные должности (чекбоксы), Select All / Deselect All, счетчик видимых сотрудников.
 - Индикатор активных фильтров на тулбаре — оранжевая иконка-счетчик, напоминающая, что часть должностей скрыта.

## 2.12.0 (2026-05-05)
 - Фильтр «только вакансии» — кнопка на тулбаре, которая показывает только вакантные позиции и их parent-юниты.
 - Интеграция с фильтром по должностям: два фильтра работают совместно (AND-логика).

## 2.13.0 (2026-05-15)
 - Печать оргструктуры на A4 (компактный вид): кнопка «🖨️ A4» в тулбаре. Можно распечатать всё дерево или только выделенный фрагмент.
 - Индикатор загрузки (спиннер) при выполнении длительных операций.

## 2.14.0 (2026-05-20)
 - Разворачивание/сворачивание юнитов — кнопка в узле дерева, которая сворачивает всех потомков юнита в одну карточку-агрегат.
 - Кнопка Expand All / Collapse All на тулбаре.

## 2.15.0 (2026-05-25)

 - Навигация по найденным сотрудникам: кнопки Next / Previous, счетчик найденных.

## 2.16.0 (2026-06-01)

## 2.17.0 (2026-06-26)
 - Реализован компактный режим отображения оргструктуры (Compact A4): оптимизированная раскладка для печати на листах A4 с уменьшенными карточками сотрудников.
 - Переделана выгрузка в PDF: улучшенный рендеринг через D3 с корректной пагинацией по страницам A4, поддержка альбомной ориентации и высокого DPI.
